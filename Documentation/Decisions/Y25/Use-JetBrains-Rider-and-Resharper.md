# Use JetBrains Rider and Resharper

## Troubleshooting Rider

Occassionally Rider can get itself into a broken state which can be fixed by:
- Restarting all instances
- Invalidating Caches with `File -> Invalidate Caches...`

A "broken state" can be:
- Solution Analysis not running
- Unit Tests not being discovered
