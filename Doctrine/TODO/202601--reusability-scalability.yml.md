# Reusability / scalability

- Compute by estimating how much the solution can be reused or scaled.
- Key elements: modularity, abstraction, config options.
- Measurement: code review, usage in other projects, config flexibility.
- Formula: Reusability = (Modules * Weight1) + (Config_Options * Weight2)
