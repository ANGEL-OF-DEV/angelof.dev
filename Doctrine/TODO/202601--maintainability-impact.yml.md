# Maintainability impact

- Compute by assessing how the task affects future updates/support.
- Key elements: code modularity, documentation, test coverage.
- Measurement: code review, doc completeness, test reports.
- Formula: Maintainability = (Modularity * Weight1) + (Docs * Weight2) + (Tests * Weight3)
