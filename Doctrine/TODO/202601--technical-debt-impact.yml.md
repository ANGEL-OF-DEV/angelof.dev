# Technical debt impact

- Compute by estimating how much technical debt is reduced or increased.
- Key elements: code quality, refactoring, known issues.
- Measurement: code analysis tools, issue trackers, code review.
- Formula: Debt_Impact = (Issues_Resolved * Weight1) - (Debt_Introduced * Weight2)
