# Impact if not done

- Compute by estimating negative consequences if the task is skipped.
- Key elements: blocked features, user pain, compliance, lost value.
- Measurement: count blocked features, survey user pain, estimate lost value ($ or time).
- Formula: Impact = (Blocked_Features * Weight1) + (User_Pain * Weight2) + (Lost_Value)
