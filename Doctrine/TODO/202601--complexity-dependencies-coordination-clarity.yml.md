# Complexity (dependencies, coordination, clarity)

- Compute by counting dependencies, required coordination, and clarity of requirements.
- Key elements: number of dependencies, teams, requirement ambiguity.
- Measurement: dependency graph, team list, requirements review.
- Formula: Complexity = (Dependencies * Weight1) + (Teams * Weight2) + (Ambiguity * Weight3)
